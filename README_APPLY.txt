Что внутри архива
- Только изменённые файлы с сохранённой структурой backend/... и frontend/...
- Эти файлы нужно положить поверх вашего проекта с заменой

После замены файлов
1. backend:
   - npx prisma migrate dev
   - или на сервере npx prisma migrate deploy
   - npx prisma generate
   - npm run build
2. frontend:
   - при необходимости npm install
   - npm run build или npm run dev

Важно
- В архив специально не вложен backend/dist, чтобы не подмешивать устаревшую сборку.
- После замены файлов backend нужно пересобрать.
- В этой версии добавлена новая миграция Prisma для аналитики сайта. Без неё графики в админке работать не будут.

Что добавлено/исправлено в этой версии
- Бан скрывает профиль, посты и сторис пользователя для остальных
- Заблокированный пользователь может войти, но видит экран блокировки с причиной и сроком
- Пока бан активен, backend режет использование функционала серверной проверкой
- Удаление аккаунта админом теперь чистит посты, сообщения и direct-диалоги безопасно через транзакцию
- Добавлен полноценный раздел "Тех поддержка"
- Пользователь может создавать личные тикеты двух типов: проблема и идея
- Администратор видит тикеты в админ-панели, отвечает от своего личного admin-аккаунта и меняет статус
- Добавлены популярные вопросы: создание, поиск, лайки, отдельная страница вопроса и официальный ответ администратора
- После закрытия вопроса администратором он автоматически уходит в архив через 24 часа при следующем серверном обращении
- Добавлен сбор аналитики посещений и действий пользователей
- В админ-панели появились метрики сайта: онлайн, активность, сессии, просмотры, популярные вкладки, страницы и действия
- Тикеты и общие вопросы вынесены в отдельные секции внутри самой админ-панели
